# 制作与质量

## 第一集

1. 人工确认角色设定、故事冲突、反转和对白。
2. 先用火柴人验证故事，再按呈现后端完成场景、表演、构图及声音。
3. 校准对白实际时长，调整停顿和反应镜头。
4. 审核低清预览，确认后再正式渲染。

## 镜头质检

- 嘴型与声音对齐，音量稳定，没有截断对白。
- 视线和角色位置连续，动作切换没有明显跳变。
- 无严重穿模、脚滑、黑帧、道具瞬移。
- 竖屏构图、字幕可读性与最终声画时长正确。

## 资产记录

每个真实资产记录 logical_id、来源、版本、授权依据、骨骼规范、引擎路径及负责维护的人。
故事目录仅定义逻辑词汇，不表示拥有具体模型；资源状态属于各个后端的绑定。

## 成本记录

每集分别记录编剧、资产制作、表演调整、渲染等待、人工修补工时，以及配音与计算费用。
比较第二、第三集与第一集的增量制作成本；首集搭建成本单独记录。

## 仓库边界

Git 保存脚本、文档、分镜和配置。大型 Unreal 资产接入前配置 Git LFS 或专用资产存储。
渲染产物、缓存、密钥和个人本地配置不入库。当前不包含第三方模型、动画、音频和材质。
