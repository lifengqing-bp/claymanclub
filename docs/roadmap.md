# Roadmap

## M0：项目初始化（完成）

- Git 仓库与基本文档。
- 能力目录、30 秒分镜草稿及引用和时间校验。

## M1：首个人工摄影棚（下一步）

- 选择并锁定引擎版本、美术风格及骨骼规范。
- 两个角色、一个房间、三个机位、少量对话动作。
- 人工制作第一集 30–60 秒竖屏视频。
- 验收：完整观看无明显穿模、脚滑、视线错误或音画错位；记录各环节工时。

## M2：复用验证

- 在相同资产上制作第二、第三集。
- 记录新增资产数、人工工时和返工镜头比例。
- 验收：无需重建摄影棚，能复用主要动作和机位；实际比较成本，不预设节省比例。

## M3：自动编排

- 配音实际时长对齐，逻辑 ID 到引擎资产绑定。
- 分镜生成 Sequencer、低清预览、审核后出片。
- 验收：同一分镜可重复构建；未知资产与 planned 资产均在执行前拒绝。

## M4：可靠批量生产

- 有界任务队列、取消、错误恢复、镜头级重跑及版本记录。
- 验收：只修改单镜头可局部重渲染；失败不丢失已完成镜头；输出可追溯。

## 内容验证

持续跟踪人工工时/成片分钟、返工镜头比例、新增资产数、观众留存及完播。
三集后决定继续、调整栏目或缩小能力范围。十集是后续系列验证目标，不是首版范围。
