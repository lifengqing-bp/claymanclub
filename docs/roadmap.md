# Roadmap

## M0：后端无关基础（完成）

- Git 仓库、设计文档、v0.2 协议及校验。
- PresentationBackend 接口、能力预检及统一产物入口。
- 可运行火柴人 SVG 分镜后端与播放预览。
- 后端隔离、不支持能力拒绝、时间线和重复输出测试。

## 已完成：v0.3 运镜

- PR #1 已合并：二维平移/旋转/缩放、绝对帧播放、v0.2 兼容与三维能力拒绝。
- 合并提交 3517213 的 CI 通过 13 个 Python/Node 和 4 个 Chromium 测试。

## M1a：逐项表演时间（本次实现）

- v0.4 镜头局部表演区间，同演员非重叠多段表演、空档和同时表演。
- 动作、情绪、对白按绝对帧切换；继续支持摄像机与旧版协议。
- 能力预检和非法/重叠区间拒绝；提供 timed-performances 示例。
- 当前仍是离散姿势，未完成连续动作、视线目标或音频同步。

## M1：火柴人故事 MVP（后续）

- 在逐项表演时间基础上加入视线目标及简单连续动作。
- 对齐实际配音，加入视频导出。
- 用两个角色、一个场景制作三集 30–60 秒短剧。
- 验收：节奏清晰、声画一致，记录每集工时及修改次数。

## M2：第二种真实呈现后端

- 根据内容需求选择 2D 角色动画、Unreal 或其他实现。
- 同一份故事经能力预检后在两个后端呈现；不改核心编排流程。
- 后端各自管理资产绑定、版本、画面质量及输出格式。
- 验收：不支持能力明确拒绝；无引擎对象侵入核心协议。

## M3：自动编导与内容复用

- 根据能力目录生成故事、分镜；输出低清预览供审核。
- 制作第二、第三集时复用角色和表演，衡量新增资产数、人工工时与返工比例。
- 内容留存和完播决定栏目是否扩展至十集。

## M4：可靠生产

- 有界任务队列、取消、失败恢复、版本溯源和镜头级重跑。
- 验收：局部改动只重做相关产物，失败不损坏已经完成的工作。
