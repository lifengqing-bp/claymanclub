# Roadmap

## M0：后端无关基础（完成）

- Git 仓库、设计文档、v0.2 协议及校验。
- PresentationBackend 接口、能力预检及统一产物入口。
- 可运行火柴人 SVG 分镜后端与播放预览。
- 后端隔离、不支持能力拒绝、时间线和重复输出测试。

## 已完成：v0.3 运镜

- PR #1 已合并：二维平移/旋转/缩放、绝对帧播放、v0.2 兼容与三维能力拒绝。
- 合并提交 3517213 的 CI 通过 13 个 Python/Node 和 4 个 Chromium 测试。

## M1a：逐项表演时间（PR #2，已合入 main）

- v0.4 镜头局部表演区间，同演员非重叠多段表演、空档和同时表演。
- 动作、情绪、对白按绝对帧切换；继续支持摄像机与旧版协议。
- 能力预检和非法/重叠区间拒绝；提供 timed-performances 示例。
- 当前仍是离散姿势，未完成连续动作、视线目标或音频同步。

## M1b：视线与连续点头（PR #3，经 PR #4 已合入 main）

- v0.5 gaze_target 角色引用、冲突校验和后端能力协商。
- nod 在表演区间内一次平滑下移/回正，Python/JS 按绝对帧采样；保留旧版静态语义。
- 程序化头部动作与摄像机组合，字幕保持固定；新增示例与测试。
- PR #3 最初合入 feat/timed-performances，PR #4 已整合到 main。
- 尚无行走、肢体混合或空间移动。

## M1c：可复用肢体动作（PR #4，已合入 main）

- v0.5 动作词汇增加 wave/bow；复用逐项表演时间和能力预检。
- 挥手抬臂、往返摆动、回正；鞠躬上身旋转、腿部固定。
- 绝对帧关节采样，保留旧版本、摄像机、字幕隔离与暂停/拖动行为。

## M1d：舞台位移与行走（PR #5，待合并）

- v0.6 独立 actor_tracks，stage_2d 偏移和确定性 walk，保留 v0.2–v0.5。
- 视线按当前舞台位置计算；位移、动作、摄像机共享帧时钟，固定字幕不受影响。
- 18 秒示例及可选 Linux 离线 MP4 demo 导出；尚无配音、碰撞或脚部锁定。
- 后端 0.6.1 加入交替抬脚和屈膝；36 秒《再来一条》作为首支叙事候选，尚待观众反馈。

## M1：火柴人故事 MVP（后续）

- 评估首支《再来一条》的节奏与步态，再制作后两集；当前不把内容验收标记为完成。
- 对齐实际配音；已有无音频离线 MP4 演示导出，生产编码流水线仍待设计。
- 用两个角色、一个场景制作三集 30–60 秒短剧。
- 验收：节奏清晰、声画一致，记录每集工时及修改次数。

## M2：第二种真实呈现后端

- 根据内容需求选择 2D 角色动画、Unreal 或其他实现。
- 同一份故事经能力预检后在两个后端呈现；不改核心编排流程。
- 后端各自管理资产绑定、版本、画面质量及输出格式。
- 验收：不支持能力明确拒绝；无引擎对象侵入核心协议。

## M3：自动编导与内容复用

- 根据能力目录生成故事、分镜；输出低清预览供审核。
- 制作第二、第三集时复用角色和表演，衡量新增资产数、人工工时与返工比例。
- 内容留存和完播决定栏目是否扩展至十集。

## M4：可靠生产

- 有界任务队列、取消、失败恢复、版本溯源和镜头级重跑。
- 验收：局部改动只重做相关产物，失败不损坏已经完成的工作。
